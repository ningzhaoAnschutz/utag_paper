# Figure 4 FRAP source-data export plan

## Purpose

This document records the implemented export of the data underlying the plots
generated by `Figure_4_FRAP_interpretation.ipynb`. The notebook and plotting
module now generate the panel-specific files described below.

The intended deliverables are publication-ready CSV files suitable for a Nature
Communications source-data package. Each file should make clear:

- what one row represents;
- whether a value is an individual observation, a mean, or a median;
- whether variability is SD or SEM;
- the measurement unit;
- the experimental condition and, where needed to distinguish trajectories,
  an anonymous cell identifier;
- which values were actually plotted;
- how the plotted values were normalized and filtered.

In this document, “source data” means the numerical values underlying the
published plots. The existing data have already undergone ROI-level processing,
quality filtering, and per-cell min–max normalization. They should therefore not
be described as unprocessed or acquisition-level “raw data.”

## Important statistical meanings in the current figures

### Individual FRAP trajectory plots

- Each thin gray trajectory is the normalized mean ROI intensity for one cell at
  each time point.
- “Mean ROI” refers to the pixel-level aggregation within that cell’s ROI.
- The green line is the arithmetic mean across cells at each time point.
- No error bar or error band is displayed in these five plots.
- The minimal accompanying summary table therefore reports only time, the
  arithmetic mean, and n.

### Combined five-condition trajectory plot

- Each colored line is the arithmetic mean across cell trajectories at each time
  point.
- The notebook calls this plot with `use_sem=False`.
- The shaded band is therefore mean ± sample SD, not mean ± SEM.
- The plotting function’s docstring says SEM, but that description is not
  correct for the present notebook call.
- The exported Figure 4F summary will contain condition, time, mean, sample SD,
  and n. The plotted limits are reconstructed as mean ± sample SD.

### Box/swarm plots

- Every black dot should be exported as an individual observation.
- The box median, quartiles, and whiskers are derived graphical summaries and do
  not need to be exported, in accordance with the requested format.
- Seaborn currently draws the box median and conventional 1.5-IQR whiskers while
  hiding boxplot fliers; the swarm layer nevertheless shows the individual
  values.
- The half-time dots are per-cell fitted parameters. They are not per-cell means
  or medians.
- The final-recovery dots are the final normalized mean ROI intensity for
  individual cells. “Mean” here describes the aggregation within the ROI, not a
  mean across cells.

## Resolved analysis and reporting scope

### Resolved: Figure 4H half-time definition

The Figure 4H fitting definition is now approved as follows:

- fit only the post-bleach recovery interval;
- set the 10-second bleach point to \(t=0\);
- retain the one-phase model \(I(t)=1-\exp(-kt)\);
- fix the asymptotic normalized recovery plateau at 1;
- calculate \(t_{1/2}=\ln(2)/k\).

The plateau is not defined by the last measured value. It is the fixed
normalized model asymptote of 1. Consequently, Figure 4H reports the time to
half of the modeled full normalized recovery toward 1.

This correction has been implemented in `frap_plotting_module.py`. The final
Figure 4H CSV should contain the corrected post-bleach half-times generated
after rerunning the relevant notebook cells.

### Resolved: Figure 4F error band

Figure 4F will retain the arithmetic mean trajectory with a shaded **sample SD**
band. The source-data table will report condition, time, mean, sample SD, and n.
Separate lower and upper columns are unnecessary because the band is mean ± SD.

### Resolved: Figure 4G and 4H reporting tables

The Figure 4G and Figure 4H CSV files will contain only the condition label and
the value represented by each black dot.

- Figure 4G: one final normalized recovered-intensity value per cell;
- Figure 4H: one corrected fitted \(t_{1/2}\) value per cell.

Box medians, quartiles, whiskers, p-values, test statistics, adjusted p-values,
and significance labels will not be included in the reporting CSV files. The
bars and stars may remain in the final figure, but they are outside the requested
source-data table scope.

### Resolved: excluded deliverables

The source-data package will not include:

- a canonical or replacement `combined_FRAP_data.csv`;
- a pre-min–max intensity column solely for canonical-file provenance;
- statistical-test CSV files for Figure 4G or Figure 4H;
- an image-provenance table for the representative images or kymographs in
  Figure 4A–E.

### Implemented requirement: plotting and export use the same data

The current combined CSV is saved before the optional downsampling step, while
the plots are generated afterward. Downsampling is currently disabled, so the
saved and plotted time grids agree. If the option were enabled later, they would
no longer agree.

The implemented workflow uses the same prepared values for plotting and
source-data export, so the exported dot values, means, and SD bands match the
figure exactly.

## Implemented notebook strategy

### Why export is integrated with plotting

Only part of the source-data export could be expressed as an independent
one-line save:

- `combined_df` is available outside the plotting functions, so the individual
  trajectory values can be exported directly.
- The half-time lists are returned and contain the values needed for the minimal
  Figure 4H table.
- The per-time-point means and SD bands for the combined plot are created inside
  the plotting function and are not returned.
- The final per-cell dataframe is also created inside its plotting function and
  is not returned.
- The five green mean trajectories are calculated inside their plotting
  function and are not returned.

Therefore, adding an unrelated one-line calculation after every image would
either duplicate analysis logic or risk exporting numbers that differ from the
figure.

### Implemented action

The plotting functions now accept optional export arguments and save the source
tables from the exact dataframes and arrays used for plotting. The notebook
shows the destination folder, panel, canonical condition name, and condition
mapping beside the relevant plot calls. Existing return values and figure
behavior are preserved.

The Figure 4H half-time table is saved explicitly from the three lists returned
by the condition-specific fits. No export reads `combined_FRAP_data.csv`.
