## Status and scope

This plan has been implemented and validated in `Figure_6B.ipynb`. The source
Excel workbooks and all other figure folders were left unchanged.

| Panel | Notebook | Plot |
|---|---|---|

## Current data preparation

### Source measurement

Every source workbook contains one row per analyzed cell. The relevant columns
are:

| Source column | Meaning |
|---|---|
| `mCH` or `mCh` | Cell-level mCherry fluorescence intensity |
| `GFP` | Cell-level GFP fluorescence intensity |
| `Ratio` or `ratio` | GFP intensity divided by mCherry intensity |
| `Normalized ratio` | Ratio after applying the acquisition-specific normalization factor |

Figure 6B plots only the `Normalized ratio` column.

The workbook formulas establish:

\[
\text{Ratio} = \frac{\text{GFP intensity}}{\text{mCherry intensity}}
\]

\[
\text{Normalized ratio} =
\frac{\text{Ratio}}{\text{acquisition-specific normalization factor}}
\]

The normalization factors already stored in the source workbooks are:

| Acquisition date | Normalization factor |
|---|---:|
| 2024-06-14 | 1.10 |
| 2024-07-03 | 2.90 |
| 2024-07-17 | 0.82 |

The plotting notebook does not recalculate these values. It reads the
precomputed `Normalized ratio` values directly. The export must therefore use
that exact column and must not create a parallel normalization calculation.

### Current reproducibility issue

The notebook currently loads files using an unsorted `os.listdir()` result and
then assigns conditions through numeric positions such as `cells[3]` and
`cells[5]`. Filesystem ordering is not a reliable scientific mapping.

Implementation should replace only this positional dependency with the explicit
filename-to-condition mapping shown above. This is a reproducibility correction
to data loading, not a change to the measurements, pooling, or plot.

Validation must confirm that the resulting 306 plotted values are identical to
the values embedded in the current notebook execution.

## Plot interpretation

The plotting dataframe has two columns:

```text
Construct
Ratio
```

Despite the temporary dataframe column name `Ratio`, its values come from the
source workbooks' `Normalized ratio` column.

The plot displays:

- one black swarm point per analyzed cell;
- a red median line;
- a box spanning the 25th to 75th percentiles;
- whiskers defined using the 5th and 95th percentiles;
- all individual points, including values beyond the whiskers;
- significance bars for significant Mann–Whitney U comparisons.

The CSV should contain only the individual black-dot values. The median,
quartiles, whiskers, swarm jitter positions, p-values, and significance stars
are derived display or statistical annotations and should not be exported.

The notebook also prints means and standard deviations, but those values are
not the red box center and are not required for the source-data CSV.

## Implemented strategy

1. Resolve the nine approved source workbooks from the current submitted-paper
   OneDrive location.
2. Define the explicit filename-to-condition mapping in the notebook.
3. Read each workbook without modifying it.
4. Extract the exact `Normalized ratio` series used for plotting.
5. Concatenate the values in the current displayed condition order.
6. Construct one dataframe with the two approved CSV columns.
7. Use the measurement column from that same dataframe for the boxplot and
   swarmplot.
8. Save the dataframe to `raw_data/` with `index=False`.
9. Preserve the current boxplot, swarmplot, Mann–Whitney tests, axis labels,
   plot dimensions, and styling.
10. Save the unchanged PNG and SVG to the local `figures/` folder.
11. Set the notebook kernel metadata to the installed `microlive` environment.

The implementation should remain inside `Figure_6B.ipynb`; no new plotting
module or helper script is needed for this single panel.

## Explicit exclusions

Do not export:

- a separate summary table;
- means or standard deviations printed by the notebook;
- box medians, quartiles, or whisker coordinates;
- Mann–Whitney statistics, p-values, or significance stars;
- swarm jitter or x-axis plotting coordinates;
- experiment IDs or acquisition dates;
- source workbook names;
- source cell labels;
- raw GFP or mCherry intensity columns;
- the unnormalized GFP/mCherry ratio;
- image provenance or microscopy filenames;
- a combined dataset spanning other Figure 6 panels.
