
The current plotting notebook does not load or display those individual values;

## Important error-bar issue

The workbook labels the plotted error values as `SEM`, but the workbook formulas
use:

```text
STDEV.P(replicates) / SQRT(n)
```

This is population SD divided by √n. Conventional SEM for replicate samples is:

```text
STDEV.S(replicates) / SQRT(n)
```

For two replicates, the current plotted error is smaller than the conventional
sample-based SEM by a factor of √2 whenever the replicates differ.

Decision: preserve the current plotted error values. Figure 5C must not be
recalculated or visually changed. The exported summary table must contain the
same error magnitudes used by the existing plot.

Because these values are not conventional sample-based SEM, the export must not
silently describe them as such. Use the explicit column name
`population_sd_div_sqrt_n_normalized_soluble_protein_ratio`, and document in
the README that this is the existing workbook calculation
`STDEV.P(replicates) / SQRT(n)`. The temporary review showed that conventional
sample-based SEM would increase the five nonzero error bars by approximately
41.4%, but that correction is not approved for Figure 5C.

## Axis-label mismatch

The final composite figure labels the y-axis:

```text
Normalized soluble protein
```

The notebook currently labels it:

```text
Ratio (T/T0)
```

The quantity is the soluble-protein ratio at temperature \(T_i\) normalized to
the 4 °C reference \(T_0\).

Decision: do not change Figure 5C. The notebook's plotted values, error bars,
axis label, and visual styling must remain as they are. This task only adds
source-data export and redirects generated output files into the local
`figures/` and `raw_data/` folders.

# Figure 5D and Figure 5E discovery

## Current input structure

`Figure_5_D_E_TM.ipynb` reads:

```text
Anti-Utag-FB CD.xlsx
```

The sheet contains two six-column blocks:

- Figure 5D: three temperature/ellipticity replicate pairs for the wild-type
  UTag intrabody, canonically labeled `Anti_UTag_IB`;
- Figure 5E: three temperature/ellipticity replicate pairs for the UTag(ΔCys)
  intrabody, canonically labeled `Anti_UTag_IB_DeltaCys`.

Each replicate contains 91 experimental observations. There are therefore:

- 273 experimental dots in Figure 5D;
- 273 experimental dots in Figure 5E.

There are no missing values in the six plotted replicate series.

## Measurement definition

Each dot is one circular-dichroism measurement:

- x: temperature in °C;
- y: ellipticity at 216 nm;
- replicate identity: one of three experimental traces.

The ellipticity column has no more specific unit in the notebook or workbook.
Until a source or caption confirms the physical unit, the CSV should use
`ellipticity_at_216_nm` without inventing a unit.

## Current fit definition

Each replicate is fitted independently with the four-parameter sigmoid:

\[
y(T) = d + \frac{a}{1 + \exp[-b(T-c)]}
\]

where:

- \(a\) is the fitted amplitude;
- \(b\) is the fitted slope coefficient;
- \(c\) is the midpoint/inflection temperature and is reported as \(T_m\);
- \(d\) is the fitted lower asymptote.

The current implementation:

- sorts each replicate by temperature;
- uses the 1st percentile for the initial lower-asymptote guess;
- uses the difference between the 99th and 1st percentiles for the initial
  amplitude;
- uses `1.0` as the initial slope;
- uses 60 °C as the initial midpoint;
- applies no parameter bounds;
- allows 20,000 function evaluations;
- creates each displayed fit line with 200 temperatures between that
  replicate's observed minimum and maximum temperature;
- records `NaN` if `curve_fit` raises `RuntimeError`.

The `use_sigmoid` function argument is currently unused; a sigmoid is always
fitted.

## Current fitted midpoint values

All six fits succeed with the present input workbook.

| Panel | Canonical condition | Replicate | Current fitted \(T_m\) |
|---|---|---:|---:|
| 5D | `Anti_UTag_IB` | 1 | 66.0193 °C |
| 5D | `Anti_UTag_IB` | 2 | 66.4001 °C |
| 5D | `Anti_UTag_IB` | 3 | 67.8643 °C |
| 5E | `Anti_UTag_IB_DeltaCys` | 1 | 79.3001 °C |
| 5E | `Anti_UTag_IB_DeltaCys` | 2 | 79.1699 °C |
| 5E | `Anti_UTag_IB_DeltaCys` | 3 | 81.1264 °C |

Notebook cells below the plots manually re-enter rounded midpoint values and
calculate `np.std`, which uses population SD by default. These printed
aggregates are not displayed in panels 5D or 5E. They should not become the
source of truth for the exported fit results.

If aggregate \(T_m\) results are required for a caption or manuscript table,
they should be calculated from the exact returned fit values with an explicitly
approved SD or SEM convention.

# Decisions resolved

## Figure 5C

- Do not correct the error bars to conventional sample-based SEM.
- Preserve the current `STDEV.P / SQRT(n)` error magnitudes and document them
  accurately.
- Export only the 12 plotted summary rows; do not export the 24 upstream
  individual replicate values.
- Do not alter the plotted data, error bars, y-axis label, or appearance.

## Figures 5D-E

- Figure 5D represents the wild-type UTag intrabody.
- Figure 5E represents the UTag(ΔCys) intrabody.
- Export every experimental dot in a panel-specific observed-value CSV.
- Export the actual displayed fitted-line coordinates for all three repetitions
  in a second panel-specific CSV.
- Do not export a separate fit-parameter table under the current
  "only what is shown" scope.
- Do not use `time`; the horizontal measurement is `temperature_c`.

## Canonical terminology

Use these ASCII labels consistently in filenames and CSV contents:

```text
wt_anti_UTag_scFv
Anti_UTag_IB
Anti_UTag_IB_DeltaCys
```

Use `IB`, not `FB`, in publication data exports. Preserve existing displayed
figure labels unless a separate figure-editing request is approved.
